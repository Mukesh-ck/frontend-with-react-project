# Himal Daily – News Portal (React + Tailwind CSS)

Final project for Frontend Development Training. Static mock data, no backend.

## Run locally
```bash
npm install
npm run dev
```
Build for deployment: `npm run build` (output in `dist/`). Deploy `dist` on Vercel or Netlify.

## Pages
Home, Latest News, Category, News Details, About, Contact (React Router, HashRouter).

## Components
Navbar, Footer, FeaturedNews, NewsCard, NewsList, CategoryMenu, SearchBar, ContactForm.

## Features
Featured news, news cards with author and date, categories, search, category filter, save/bookmark stories, validated contact form, responsive layout.
